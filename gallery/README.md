# 讲义图谱（gallery/）

主页「讲义与知识图谱」区块的图源目录。区块由 `gallery/manifest.json` 驱动，**不要直接改 index.html 里那段 HTML**，下次跑脚本会被覆盖。

---

## 一、选图标准

按优先级从高到低，三条同时满足才放首屏：

**1. 重难点优先**
家长能立刻认出的"难"，才值得占位置。

- 初中：欧姆定律、电功率、电学题型与易错点、比热容、浮力压强、简单机械
- 高中：匀变速直线运动、共点力平衡、牛顿定律、曲线运动、功能关系
- 反过来，"生活用电""声现象""光的反射"这类章节做得再漂亮也不放首位——家长不觉得难，就没有价值感

**2. 缩略图可读**
这是最容易被忽略的一条。手机上两列显示，每张只有约 210px 宽，等于原图的 40%。

- 能过关的：有大标题、有分块色块、有图示、留白够
- 过不了关的：纯公式罗列（如"必修二公式大全"）、满页小字表格
- 判断方法：把图缩到 210px 宽自己看一眼，**还能看出"这是讲什么的"就留，只剩一片灰就撤**

**3. 同一套只选 1–2 张，且功能不同**
一套 5 页的讲义全放上去，家长看到的是"重复"，不是"丰富"。
同一套里优先选：概念页（结构最清楚）+ 题型/易错页（最能体现教学价值）。

**4. 风格统一**
蓝色活页本这一套视觉最统一，优先。其他配色（如比热容的暖色版）只在内容足够重难点时才用，且放在后半段。

## 二、新增一张图

```bash
# 1. 把图片放进 gallery/
cp ~/Downloads/新图.png gallery/junior-xxx.png

# 2. 在 gallery/manifest.json 的 items 里加一条
#    pick=true 才会显示，order 决定顺序（越小越前）

# 3. 重新生成
python3 src/build_gallery.py
```

`manifest.json` 里每条字段：

| 字段 | 说明 |
|---|---|
| `file` | 文件名，必须在 `gallery/` 下 |
| `title` | 图下方显示的名字，如「欧姆定律」 |
| `stage` | 学段，会拼成「欧姆定律 · 初中」 |
| `topic` | 章节，仅作备注 |
| `pick` | `true` 才上主页；`false` 留在库里备选 |
| `order` | 排序，越小越靠前 |
| `why` | 为什么选/不选它，写给未来的自己看 |

脚本会校验：图片不存在直接报错退出，不会生成半截页面。

## 三、图片规范

- **宽度 520px 即可**，页面最大显示宽度约 444px，2 倍屏够用
- **长宽比接近 3:4**（如 520×693）。页面按 3:4 裁切并保留顶部，太长的图底部会被切
- **标题必须落在顶部 1/5 区域内**，否则会被裁掉
- 格式：`.jpg`（照片感、体积小）或 `.png`（线条清晰、体积大）
- 单张控制在 200KB 以内，8 张合计 < 1.5MB，手机上才不卡

---

## 四、换掉首屏第一张

第一张是"门面"，家长滑到这里第一眼看到的就是它。换的顺序：

1. 在 manifest 里把新图 `order` 设为 1
2. 原来第一张的 `order` 往后挪
3. 跑脚本

建议第一张永远放**概念页**（不是公式页、不是实验页）——概念页的结构感最强，缩到 210px 还能看出层次。

## 五、常见问题

**Q：图更新了但页面没变？**
浏览器缓存。强制刷新（电脑 Cmd+Shift+R），或改文件名加版本号（`junior-ohm-1-v2.jpg`）。

**Q：想临时撤掉一张？**
把 `pick` 改成 `false`，不用删文件，跑脚本即可。

**Q：科目页（math/physics/chemistry）的图呢？**
那是另一套，由 `src/data/*.json` 的 `evidence.gallery` 字段控制，跑 `python3 src/build.py` 生效，不走这个 manifest。
