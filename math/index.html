小学六年级 · 单位「1」
一本书 120 页，读了 1/4，还剩多少页？
多数学生会这样错：120 × 1/4 = 30，答「还剩 30 页」。算得没错，但答的是「读了多少」。
  1. 圈出分率句：1/4
  2. 「的」字前面是单位「1」→ 全书 120 页
  3. 写关系式：剩下 = 120 × (1 − 1/4) = 90 页
  4. 回代检验：读的 30 + 剩的 90 = 120 ✓
「的」前「比」后找标准；先写关系式，再算不迷糊
出处：六年级第 1 课《单位 1 与应用题拆解》四步卡
初三 · 一元二次方程
解方程 x² − 5x + 6 = 0。
多数学生会这样错：上来就套求根公式：算判别式、开根号、化简，六分钟过去，还可能算错。
  1. 先问：能不能十字相乘？找两个数，和 = −5、积 = 6 → −2 和 −3
  2. 分解成 (x−2)(x−3) = 0 → x = 2 或 x = 3
  3. 只有分解不出来，才动求根公式；配方法放在最后
先分解，再配方，最后才套公式
出处：初三数学第 7 课《一元二次方程解法选择》备课计划
🧩 我怎么教
不是多讲几道题，是给一套能复用的方法
1. 先画图，再列式
几何题先画“拆分路线图”，把大图拆成认识的三角形、四边形；函数题先画图象再写式，用数形结合代替硬算。
2. 题型建模
把全等模型、动点问题、二次函数最值、应用题四类关系归纳成固定解法，见到题先认模型再下笔。
3. 按评分标准写过程
照中考阅卷的踩分点写：条件写全、结论回扣、单位带齐，会做的题一分不丢。
4. 错题回炉
错题归档并标注是概念错、方法错还是计算错，一周后重做一遍，不让它第二次错。

❓ 家长常问
关于数学辅导的常见问题
孩子几年级补数学最合适？
小学四五年级是应用题方法成型期，这时候补最省力；初中的两个坎是七下几何入门和八下函数，卡住时及时补，不要拖到初三总复习。
一听就懂，一做就错，怎么办？
听懂是被动输入，会做是主动输出。我的做法是讲完立刻当堂做 3 道变式题，错的当场纠正，不留到课后。
几何辅助线总是想不到？
不靠灵感，靠模型。截长补短、倍长中线、旋转构造全等、遇中点想中位线——按模型练到位，看到条件就能对应上。
函数和方程怎么打通？
函数图象是方程的几何表达：交点坐标就是方程组的解，函数值大于零的区间就是不等式的解集。用图象判根、用方程求点，两者一起练。
计算粗心能改吗？
能。用限时训练和检查清单：符号有没有抄错、单位有没有统一、答的是不是题目问的量，三遍核对，一学期能见效。
